## 지금 — 신청 1건 「찾기 시작 → 연락 문구 준비」

가정: 공식몰 · 오프라인 매장 · 해외몰을 한 곳씩 확인해 3건 기록, 그중 매장에 재고 있음. 연락은 문자.

| 단계 | 누름 | 입력 | 화면 넘김 | 다른 앱 · 탭 |
|---|---|---|---|---|
| 목록에서 그 신청 찾기(최근 접수가 위 — 오래 기다린 건 아래) | 0 | 0 | 1 + α | 0 |
| 카드 열기 | 1 | 0 | 0 | 0 |
| 02 공식몰 검색 열기 → 돌아오기 | 1 | 0 | 1 | 2 |
| 03 지도에서 매장 찾기 → 돌아오기 | 1 | 0 | 0 | 2 |
| 04 해외몰 검색 → 돌아오기 | 1 | 0 | 0 | 2 |
| 05 로 내려가기 | 0 | 0 | 1 | 0 |
| 05 기록 3건(판매처 · 가격 · 상태 버튼) | 9 | 6 | 0 | 0 |
| 06 으로 내려가 번호 「보기」 | 1 | 0 | 1 | 0 |
| 번호 복사(길게 누르기 · 범위 · 복사) | 3 | 0 | 0 | 0 |
| 상품명 복사(길게 누르기 · 범위 · 복사) | 3 | 0 | 0 | 0 |
| 문자 앱 열기 · 번호 붙여넣기 | 2 | 0 | 0 | 1 |
| 연락 글을 손으로 쓰기(상품명 · 사이즈 · 가격 · 판매처 종류) | 1 | 1(긴 글) | 0 | 0 |
| **합계** | **23** | **7** | **4 + α** | **7** |

**조작 수(누름 + 입력 + 화면 넘김) = 34.** 다른 앱 · 탭 전환은 매장 · 몰을 실제로 봐야 해서 줄일 대상이 아니다(같은 수로 둔다).

그다음 「정리」(목표 측정 범위 밖): 상태를 「확보」 → 「연락 완료」로 바꾸기 4누름, 확보 상품 등록(확보 상품 탭 → 주소 · 사이즈 다시 입력) 약 8누름 · 3입력, 다음 신청 찾기 1 화면 넘김.
