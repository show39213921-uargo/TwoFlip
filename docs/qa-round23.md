# 23차 — 22차 QA 반영(U-1 ~ U-5, 작음)

> 22차 QA(v=3eba7d63071e) 버그 0건 · 오픈 가능. 진행 상황 · 연락 문구 쪽 작은 수정이다. **프런트만 바뀐다**(백엔드 · SQL 없음 — 잠금 · 요청 제한 · 토큰 규칙 그대로).
> U-1 은 첫 실제 고객 연락 전에 들어가야 한다.

## 바뀐 것

| 항목 | 어디서 | 무엇을 | 어떻게 확인 |
|---|---|---|---|
| U-1 「찾았어요」 문구 — 답하는 길 하나 | 관리자 06 연락 문구 | 확인 링크가 있으면 4번째 줄 「아래 링크에서 「구매할게요」를 눌러 주세요. 문자로 답하셔도 돼요.」 → **다음 줄에 주소만**(이름표 없이 — 문자 앱이 링크로 잡게) → 접수번호. 「이 메시지에 답장 주세요」는 링크가 없을 때(토큰을 못 만듦)만 | [QA] 신청 05 「재고 있음」 → 06 문구가 6줄인가(인사 · 찾았어요 · 가격 빈칸 · 안내 · 주소 · 접수번호). 「진행 상황 · 답하기:」 글자가 없는가 |
| U-2 답한 뒤 단계 한 줄 | 진행 상황 「찾았어요」 | 답이 있으면(또는 기한이 지나 버튼이 없으면) 한 줄이 「문자로 가격을 보내 드렸어요.」까지만. 「답 바꾸기」로 버튼이 다시 나오면 「…아래에서 답해 주세요.」 | 구매할게요 → 한 줄이 짧아지는가 → 답 바꾸기 → 원래 문장 |
| U-3 「접수」에서도 상태 확인 창 | 관리자 06 「문구 복사」 · 「문자로 열기」 | 상태가 접수 · 탐색 중 · 확보면 묻는다 — 찾았어요: 「연락을 보냈으면 상태를 「연락 완료」로 바꿉니다.」 / 못 찾았어요: 「연락을 보냈으면 상태를 「취소」로 바꿉니다.」 → 안내 줄 「{접수번호} 연락 보냄을 기록했습니다. 상태를 「취소」로 바꿨습니다.」. 확인 창 「취소」면 상태는 그대로, 연락 보냄만. **「못 찾음」 = 「취소」는 재영 확인 대기** — `assets/js/admin-rules.js` `NOT_FOUND_STATUS` 한 줄로 바꾼다 | 「접수」 [QA] 신청에서 찾았어요 / 못 찾았어요를 각각 복사 → 확인 창 문구 · 상태 · 고객 화면 단계가 서로 맞는가 |
| U-4 「답 바꾸기」 뒤 초점 | 진행 상황 답 상자 | 버튼이 다시 나오면 초점이 「구매할게요」로. 답한 뒤에는 결과 문장(「답을 받았어요…」, role=status · tabindex=-1)에 초점 | 키보드로 답 → 결과 문장에 초점 · 낭독 / 답 바꾸기 → 「구매할게요」에 초점(머리로 튀지 않음) |
| U-5 조회 칸 예시 | 진행 상황 조회 칸 | 접수번호 예시 「예: 1a2b3c4d」(예전 [QA] 번호를 지움). 번호 칸 「0000」은 그대로 | 칸 예시 글 |

## 안 바꾼 것
- 진행 상황 화면에 가격 · 판매처 없음. 잠금 · 요청 제한 · 토큰 규칙 그대로. 「못 찾았어요」 문구(새 약속 없음) 그대로. 신청서 · 바로 구매 배치 그대로.

## QA 가 볼 것 (실서버 — `[QA]` 이름 · 010-0000-0000 만, 신청 2건이면 충분)
1. [QA] 신청 1 — 상태 「접수」 그대로 05 「재고 있음」 → 06 문구 6줄 · 주소 줄에 이름표 없음 · 판매처 이름 · 매입가 · 메모 없음 → 「문구 복사」 → 확인 창 「…「연락 완료」로 바꿉니다.」 → 상태 「연락 완료」 · 안내 줄 한 문장.
2. 복사한 주소로 고객 화면 → 「찾았어요」 + 「…아래에서 답해 주세요.」 → 키보드로 「구매할게요」 → 한 줄이 「문자로 가격을 보내 드렸어요.」 · 초점이 「답을 받았어요…」 → 「답 바꾸기」 → 초점 「구매할게요」 · 한 줄이 다시 「…아래에서 답해 주세요.」.
3. [QA] 신청 2 — 상태 「접수」 그대로 05 「품절」 → 06 「못 찾았어요」 복사 → 확인 창 「…「취소」로 바꿉니다.」 → 상태 「취소」 · 안내 줄 「… 상태를 「취소」로 바꿨습니다.」 → 고객 화면(접수번호 + 0000) 「이번엔 못 찾았어요」.
4. 같은 흐름에서 확인 창 「취소」를 누르면 상태는 「접수」 그대로 · 06 「연락 보냄」만 남는가(신청 하나로 한 번만 보면 된다).
5. 조회 칸 예시 「예: 1a2b3c4d」 · 「0000」.
6. 회귀 — 22차 D-1 ~ D-8 의 나머지는 그대로여야 한다. 끝나면 [QA] 신청 2건 삭제.
