# 22차 — 4단계: 진행 상황 조회 · 확인 링크 · 「못 찾음」 문구 · 답장 대기

> 고객이 「지금 어디까지 왔는지」를 직접 보고, 「찾았어요」 연락에 화면에서 바로 답한다. 운영자는 「못 찾았어요」도 정해진 문구로 보내고, 답이 안 온 신청을 한눈에 본다.
> **백엔드 · SQL 이 같이 바뀐다.** 배포 순서는 [docs/deploy.md](deploy.md) 그대로 — ① 백엔드 + 마이그레이션 `2026-10-16_status` + 서버 `.env` 에 `STATUS_SECRET` ② 공개 엔드포인트 확인 ③ 프런트.
> 시안: https://claude.ai/artifact/MksiBTbSsKsRPbniisXhsy (결정 ① HMAC 링크 · ② 어두운 답 상자 + 연두 「구매할게요」 · ③ 보조 문구 3줄 반영)

## 만들지 않은 것(브리프 「하지 말 것」)
- 결제 연동 · 자동 문자 발송 · 재입고 알림 · 「알려 드릴까요」 — 없다. 「못 찾았어요」 문구에도 새 약속을 넣지 않았다.
- 진행 상황 화면에 가격 없음. 신청서 · 바로 구매 화면 배치는 그대로(링크 하나만 늘었다).

## QA 확인 순서 D (실서버 — `[QA]` 이름 · 010-0000-0000 만)
1. 첫 페이지에서 `[QA]` 신청 → 완료 카드 「진행 상황 보기 →」 → `status.html` 이 열리고 주소창에서 `t=` 가 사라지는가. 「접수됨」 단계 · 상품명(아직 없으면 「신청하신 상품」) · 사이즈 · 접수일만 보이는가.
2. 관리자 06 — 05 에 「재고 있음」 기록 → 06 이 「찾았어요」로 채워지고 끝 줄이 `진행 상황 · 답하기: https://twoflip.u-argo.com/status.html?t=…` 인가(완료 카드 링크와 **같은 값**). 「문구 복사」 → 「연락 보냄 · 시각」 + 상태를 묻는 확인 창 → 「연락 완료」. **「문자로 열기」는 누르지 않는다**(실제 문자 앱).
3. 복사한 링크를 다른 브라우저(시크릿)로 열기 → 「찾았어요」 + 답 상자. 「구매할게요」 → 「답을 받았어요. 입금 방법을 곧 문자로 알려 드릴게요.」 + 「{시각}에 「구매할게요」로 답하셨어요.」
4. 「답 바꾸기」 → 「이번엔 괜찮아요」 → 「알겠어요. 다음에 또 찾을 게 있으면 링크만 보내 주세요.」 (30분이 지나면 「답 바꾸기」가 없어진다 — 서버도 409 `reply_locked`)
5. 관리자 「새로고침」 → 안내 줄 「… 새 답 1건이 있습니다.」 · 목록 칩 「괜찮아요 · 시각」 · 06 「취소로 바꾸기」(확인 창 → 「취소」) · 「상태 변경 이력 보기」에 「고객 답: …」 줄. 답하기 전에는 알약 「답장 대기」에 그 신청이 들어 있는가.
6. 두 번째 `[QA]` 신청 — 05 에 「품절」만 기록 → 06 이 「못 찾았어요」로 시작하고 문구가 다섯 줄(새 약속 없음)인가. 복사 → 고객 화면이 「이번엔 못 찾았어요」 + 「KREAM 링크로 신청하기」.
7. 설정 「답장 기한」에 `1` → 고객 화면에 「{날짜 시각}까지 답해 주시면 잡아 둘게요.」. 다시 비우기 → 줄이 사라진다. (기한 넘김은 1시간을 기다려야 해서 로컬 시험으로 대신했다 — 아래)
8. 조회 — 접수번호 + 틀린 뒤 4자리 → 「접수번호나 번호를 다시 확인해 주세요.」. 같은 접수번호로 5번 틀리면 10분 동안 「잠시 후 다시 시도해 주세요.」(맞는 번호도). 끝나면 `[QA]` 신청 두 건을 지운다.

## 로컬에서 확인한 것
- 백엔드 `php tests/run.php` — 진행 상황 7개 포함 전부 통과. 응답 칸은 name · size · receivedDate · stage · reply · replyAt · replyDeadline 만(스냅샷 테스트로 고정), 토큰은 로그 · 오류 기록에 남지 않는다.
- 프런트 `npm test` 전부 통과. 고객 화면 3상태 × 5폭(320~1280) × 다크/라이트 × 글자 3단계 가로 넘침 0 · 콘솔 오류 0.
- 로컬 서버(sqlite) 끝까지: 신청 → 토큰 → 관리자 찾았어요 연락 → 고객 답 → 칩 · 새 답 · 이력 → 못 찾았어요 → 기한 지남.
