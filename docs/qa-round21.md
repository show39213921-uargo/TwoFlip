# 21차 — 마크 · 아이콘 · 진입 QR · 브랜드 문서

> 20차 QA 를 도는 동안 만든 것이다. **고객 화면 배치 · 문구 · 색은 그대로**다. 바뀌는 건 브라우저 탭 아이콘 파일과 휴대폰 홈 화면 아이콘(새로 생김)이다. 프런트만 바뀐다(백엔드 · SQL 없음).
> 파일 · 규격은 [docs/brand.md](brand.md).

## 바뀐 것

| 항목 | 어디서 | 무엇을 | 어떻게 확인 |
|---|---|---|---|
| 탭 아이콘 | 모든 페이지 `<head>` | 페이지마다 넣어 둔 `data:` 아이콘을 파일 `assets/img/favicon.svg` 로 옮겼다(**같은 그림**) | 탭 아이콘이 전과 같은 「어두운 사각 + 연두 화살표 두 개」인가. 404(`/abc/def`)에서도 보이는가 |
| 홈 화면 아이콘 | 모든 페이지 `<head>` | `assets/img/brand/apple-touch-icon.png`(180×180)를 새로 붙였다. iOS 「홈 화면에 추가」 때 쓰인다(전에는 페이지 캡처) | (실기기) iOS Safari → 공유 → 홈 화면에 추가 → 아이콘이 마크인가 |
| 진입 QR | `assets/img/brand/twoflip-qr.*` · `twoflip-qr-card.*` | 첫 페이지(`https://twoflip.u-argo.com/`)로 들어가는 QR(오류 정정 H · 가운데 마크)과 인쇄용 카드(A6 비율) | (실기기) iOS · 안드로이드 카메라로 QR · 카드 PNG 를 찍으면 첫 페이지가 열리는가(이 PC 크롬엔 판독 기능이 없어 자동 확인 못 함) |
| 굵은 워드마크 시안 | `assets/img/brand/twoflip-logo-white-bold.svg` | 만들어만 뒀다(600 굵기). **화면에 적용 안 함** — 결정 ③ 은 재영 결정 | 확인할 것 없음(헤더 글자는 그대로) |

## QA 가 볼 것
1. 다섯 페이지(첫 페이지 · 소개 · 바로 구매 · 관리자 · 404) 탭 아이콘이 보이고 콘솔 · 네트워크에 아이콘 404 가 없는가.
2. 실기기 — QR 카드 PNG 를 다른 화면에 띄워 iOS · 안드로이드 카메라로 찍기 → 첫 페이지. iOS 홈 화면에 추가 → 아이콘.
3. 회귀 전체(7번 B). 고객 화면은 20차와 같아야 한다.
