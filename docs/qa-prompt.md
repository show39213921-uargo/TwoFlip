# TwoFlip 화면 QA

> 다른 Claude 세션(브라우저 사용)이나 사람에게 이 문서를 그대로 넘긴다. 테스트 계정 비밀번호는 여기 적지 않는다 — 재영이 따로 전달한다.
> 화면이 바뀌면 이 문서의 체크리스트도 같이 고친다. (작성 2026-10-14 · 관리자 로그인 화면 PR #8 기준)

## 너의 역할

TwoFlip(KREAM 링크로 신청받아 매장·공식몰에서 상품을 확보해 주는 구매대행 서비스)의 웹 화면을 QA 한다.
코드를 고치지 않는다. 화면을 직접 써 보고, 문제를 재현 절차와 함께 보고만 한다.

## 대상

| 화면 | 주소 | 비고 |
|---|---|---|
| 신청 화면(실제) | https://twoflip.u-argo.com | 신청이 **실제 서버 DB** 에 저장된다 |
| 신청 화면(테스트 모드) | https://twoflip.u-argo.com/?demo=1 | 신청이 이 브라우저에만 저장. 끝낼 때 `?demo=0` |
| 관리자 화면 | https://twoflip.u-argo.com/admin.html | 로그인 필요. 계정은 재영에게 받는다 |

## 반드시 지킬 것

1. **실제 서버에 넣는 테스트 신청은 이름을 `[QA] 이름` 으로, 휴대폰은 `010-0000-0000` 으로**만 한다. 실제 고객 신청(이름에 `[QA]` 가 없는 것)은 **상태·재고·담당자를 바꾸거나 지우지 않는다** — 보기만 한다.
2. QA 가 끝나면 관리자 화면에서 `[QA]` 신청을 전부 지운다(06 신청자 → 「이 신청 삭제」).
3. 요청 제한이 있다: 같은 IP 에서 신청 10분 5번, 관리자 로그인 시도 10분 10번. 넘으면 「너무 잦습니다」가 나오는 게 **정상**이다(버그 아님). 일부러 많이 두드리지 않는다.
4. 아래 「알려진 동작」은 버그로 올리지 않는다.
5. 비밀번호·접속 키를 보고서·스크린샷에 남기지 않는다.

## 알려진 동작(버그 아님)

- 실제 신청 화면에서 KREAM 링크를 넣으면 「지금은 KREAM 정보를 불러올 수 없습니다. 신청은 그대로 할 수 있습니다」가 나온다 — 서버 IP 를 KREAM 이 막고 있다. 신청은 저장되고, 나중에 사무실 PC 가 KREAM 정보를 채운다(`twoflip_backend` 의 `tools/kream-fill.php`).
- 테스트 모드에서는 「테스트 모드에서는 KREAM 상품 정보를 불러오지 않습니다」.
- 관리자 화면의 공식몰·지도·해외 링크는 **검색 링크**다(재고를 자동 조회하지 않음). 재고 확인 기록은 전부 「수동」.
- 「KREAM 대비」는 KREAM 수수료·배송비 전 금액이다.
- 신청 KREAM 정보가 없는 카드는 「상품 정보 없음」 + 01 칸에 브랜드·모델번호 직접 입력 칸이 보인다.

## 점검 환경

- 데스크톱 1280px 이상 · 모바일 375px — 둘 다
- 라이트 · 다크 모드 — 둘 다(OS/브라우저 설정)
- 가능하면 Chrome + Safari(iOS) 또는 Samsung Internet

## 체크리스트

### A. 신청 화면 — https://twoflip.u-argo.com

- [ ] 첫 화면: 히어로 · 진행 순서 4단계 · 신청 카드가 깨짐 없이 보인다. 375px 에서 가로 스크롤이 생기지 않는다
- [ ] http:// 로 열면 https:// 로 넘어간다
- [ ] 빈 채로 「신청하기」 → 칸마다 빨간 안내(KREAM 주소·사이즈·이름·휴대폰·동의), 첫 오류 칸에 커서
- [ ] KREAM 주소 검증: `kream.co.kr/products/1068133`(스킴 없음)·`https://www.kream.co.kr/products/1068133?size=270` 은 통과 / `https://www.musinsa.com/...` → 「KREAM(kream.co.kr) 상품 주소만 받습니다」 / `https://kream.co.kr/search?keyword=x` → 「KREAM 상품 페이지 주소…」
- [ ] 휴대폰: `010 1234 5678`·`01012345678` 통과 / `02-123-4567` 거절
- [ ] 이름 31자 · 사이즈 21자 · 요청사항 501자 → 막힌다
- [ ] 동의 체크 없이 → 거절
- [ ] 정상 신청(`[QA]` 규칙대로) → 「신청이 접수되었습니다. 접수번호 xxxxxxxx …」, 입력칸이 비워진다. **접수번호를 적어 둔다**
- [ ] 키보드만으로(Tab·Space·Enter) 신청까지 갈 수 있다. 포커스 테두리가 보인다

### B. 테스트 모드 — https://twoflip.u-argo.com/?demo=1

- [ ] 위에 연두색 「테스트 모드」 띠, 「관리자 화면 →」·「테스트 끝내기」 링크
- [ ] 신청 → 「테스트 신청이 이 브라우저에 저장되었습니다」
- [ ] 다른 페이지로 갔다 와도(같은 탭) 테스트 모드 유지 / `?demo=0` 이면 띠가 사라지고 실제 모드

### C. 관리자 로그인 — https://twoflip.u-argo.com/admin.html

- [ ] 들어오자마자 **로그인 화면만** 보인다(탭·버튼·신청 목록이 보이면 버그)
- [ ] 빈 값 → 「아이디와 비밀번호를 넣어 주세요」 / 틀린 비밀번호 → 「아이디 또는 비밀번호가 맞지 않습니다」, 비밀번호 칸이 비워진다
- [ ] 아이디 대소문자 무관(예: `JaeYoung` = `jaeyoung`)
- [ ] 로그인 → 관리자 화면, 헤더 「OO 님 · 새로고침 · 로그아웃」, 「서버」 탭 선택 상태
- [ ] 「로그인 유지(30일)」 체크 후 새로고침·탭 닫고 다시 열기 → 로그인 화면 없이 바로 관리자 화면
- [ ] 체크 없이 로그인 → 새 탭에서 열면 로그인 화면
- [ ] 로그아웃 → 로그인 화면 「로그아웃했습니다」, 뒤로가기로 신청 목록이 다시 보이지 않는다

### D. 관리자 — 목록

- [ ] A 에서 넣은 `[QA]` 신청이 목록에 있다(접수번호·접수 시각·사이즈·이름·가려진 번호 `010-****-0000`)
- [ ] 상단 숫자(전체·접수·탐색 중…) 클릭 → 그 상태만 / 「재고 확인 필요·있음·없음」 필터 / 검색(이름·번호·모델번호·접수번호·메모)
- [ ] 「새로고침」 → 최신 목록

### E. 관리자 — `[QA]` 신청 카드(펼쳐서)

- [ ] 01 KREAM: 정보가 없으면 브랜드·모델번호 입력 → 「적용」(예: `Salomon` / `LD0274200`) → 카드 제목·02~04 링크가 바뀐다
- [ ] 02 공식 홈페이지 · 03 근처 오프라인(네이버·카카오 지도) · 04 해외 공식몰 링크가 새 탭으로 열리고 검색어가 맞다
- [ ] 설정 → 기준 지역 `강남` → 03 지도 검색어가 「강남 살로몬 매장」이 된다
- [ ] 05 재고 확인: 판매처 비우고 「기록」 → 안내 / 정상 기록(종류·판매처·사이즈·재고 있음·가격) → 목록 배지 「재고 있음 1곳 · 최저 …원」, 「KREAM 대비」 표시, 확인한 사람 이름
- [ ] 재고 상태를 「품절」로 → 배지 「재고 없음」, 최저가에서 빠짐 / 「지금 다시 확인함」 → 시각 갱신 / 다른 사이즈로 기록 → 「다른 사이즈」 표시·최저가 제외 / ✕ 로 삭제
- [ ] 해외(USD 등) 기록 + 설정 환율 입력 → 원화 환산, 환율 없으면 「환율 필요」
- [ ] 06 신청자: 번호 「보기/가리기」, 담당자 지정 → 목록에 「담당 OO」, 상태를 바꾼 뒤 「상태 변경 이력 보기」 → 「접수 → 탐색 중 · OO」
- [ ] 상태 셀렉트 변경 → 저장되고 새로고침해도 유지
- [ ] 다른 계정(있다면)으로 로그인 → 같은 변경이 보인다(3명 공유)
- [ ] 마지막에 「이 신청 삭제」 → 확인창 → 목록에서 사라짐

### F. 관리자 — 기타

- [ ] JSON·CSV 내보내기 파일이 받아지고, CSV 를 엑셀로 열면 한글이 깨지지 않는다
- [ ] 「이 브라우저」 탭 → 「샘플 넣기」 → 샘플 3건(실제 KREAM 정보 포함) / 「이 브라우저 데이터 비우기」
- [ ] 「JSON 파일」 → 방금 내보낸 JSON 열기 → 목록이 보인다
- [ ] 375px 에서 카드·재고 표·입력 칸이 넘치지 않는다(표는 가로 스크롤 허용)

## 보고 형식

각 문제마다:

```
[심각도] 높음(데이터 손실·노출, 신청 불가) / 중간(기능 오동작) / 낮음(표시·문구)
화면: 신청 / 테스트 모드 / 관리자-로그인 / 관리자-목록 / 관리자-카드(01~06)
환경: 브라우저 · 폭(1280/375) · 라이트/다크
재현: 1) … 2) … 3) …
기대: …
실제: …
첨부: 스크린샷(비밀번호·전화번호 원문은 가리기)
```

마지막에 요약: 체크리스트 통과/실패 개수, 높음 등급 목록, 삭제한 `[QA]` 접수번호 목록(지웠는지 확인용).
