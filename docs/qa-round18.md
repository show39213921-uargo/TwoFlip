### 오류 내는 법(QA)
- 개발자 도구 콘솔이나 자동화 도구로 바로 `throw` 하면 브라우저가 「Script error.」로 가린다. 이건 일부러 보내지 않는다.
- **페이지 안 스크립트로** 낸다. 테스트 모드(`?demo=1`) 페이지에서 아래를 실행한다. 메시지에 `[QA]` 를 넣어 구분한다.

```js
const s = document.createElement('script');
s.textContent = "setTimeout(() => { throw new Error('[QA] 오류 알림 확인'); })";
document.body.append(s);
```
